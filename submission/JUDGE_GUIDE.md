# Judge walkthrough — IntentCart 4.3

Start with the README in the source archive. Install the pinned lock file, run `python -m intentcart`, and open the displayed localhost origin. Planning, graphics and report reading work offline with provider cap zero. The local interface is not a hosted public deployment.

1. Open `/missions`. Describe a two-display workstation, review its typed settings and build. Explore the connected 3D components and the complete bill of materials. Graphics and the local guide consume no model credits.
2. Investigate an unknown specification. Change the budget or exclude a component. Inspect the supported repair or explicit deferral. Compatibility and bounded optimality are separate claims.
3. Review the exact quote. Sandbox checkout requires existing sandbox credentials and separate buyer approval; do not supply real payment details. The retained actual USD 279 capture/full-refund evidence is `workstation-sandbox-verification.json`; replaying a payment is unnecessary to review it.
4. Open `/workbench` for curated source dates, variants, declared inventory, price uncertainty, preference comparisons and exports. This workspace cannot create payments. Real specification records do not establish live prices or hardware testing.
5. Open `/research` and `/reliability`. Compare finite-budget policies, inspect negative learning results and step through saved reduced failures. These pages read evidence; they do not launch provider calls or payment mutations.
6. Read `live-validation.json`: native fixture four supported matched/repeated trials; harder driver task one supported, one failed and two unattempted. All seventeen requests, initial failures and aggregate free-credit use are disclosed. The actual model is Haiku 4.5 through Astropods; no GPU hardware or training claim.
7. Run `python scripts/audit_external_validation.py` and the commands in `COMBINATORIAL_VALIDATION.md`. Full traces/source hashes make local consistency reproducible. Finite authored cases and fictional personas are software checks, not human participants.
