# IntentCart 4.2 — Evidence agent

Implemented October 14, 2026 at $0 cash with external-call ceiling zero. `/agent` is an owned, reviewed evidence workspace; `/missions` retains the cinematic fixture studio and now supports optional human preference comparisons.

## Implemented behavior

The agent has bounded search, inspect, clarify, recommend and defer actions. Strict model proposals use the same tool validator as deterministic local policies. A source must belong to a discovered, available exact product variant. Repeated inspections, fabricated basket IDs and stale revisions are rejected. One explicit model-step request can dispatch at most one paid inference request after durable shared call/cost reservation; lost/invalid responses retain reservations and no automatic retry occurs. Concurrent human edits reject stale model replies. There is no payment, browsing, arbitrary code or permission-granting tool.

The default is an explicitly labeled deterministic local policy. No live language-model trajectory has been verified. Model configuration and schema/fake-provider tests do not establish actual inference. The UI cannot call a model on page load; One model step stays disabled under current configuration.

The curated collection contains the MacBook Air M1/2020, Plugable UD-6950PDH August-2024 revision, Dell P2422H, matching included dock adapter, and an explicitly declared example pair of owned HDMI cables. Apple, Plugable and Dell official specifications were manually reviewed October 14. Field, value, unit, variant, source URL, review date and paraphrased support are bound together. Native Apple connection support and Plugable's DisplayLink compatibility claim are distinct. The charging target derives from the supplied Apple 30W adapter and is not a measured charging rate. HDMI cable capability and all price allowances are scenario assumptions requiring review. OS requirements, HDCP restrictions and graphics-use caveats are shown; compatibility is limited to the represented constraints. This is not a hardware test or merchant quote, and the curated agent cannot create checkout.

`import_evidence.py` validates a bounded operator-curated file without fetching URLs or replacing active data. Numeric facts reject booleans, units/variants must match and manufacturer origins must be reviewed. Validation is not source authenticity or a universal truth guarantee.

## Human preference ranking and consent

A 512-particle Bayesian model estimates four nonnegative weights: lower cost, driver simplicity, charging capacity and dock refresh capacity. The last feature is a dock specification for potential upgrades, not the actual refresh rate of the complete setup. Only explicit pairwise human choices among supported configurations update the posterior. Skip is neutral; tie uses a declared heuristic likelihood. The main Missions route recomputes valid baskets under the estimate, invalidates old quotes, and quotes the selected canonical basket. Repair still prioritizes changed slots. Preference-ranked certificates retain supported feasibility but mark optimality unresolved; no true-utility, cost-optimality or recommendation-quality claim follows. The certificate fingerprint includes preference history. Hard requirements and exact approval remain separately enforced. The original seven-attribute `/learn` lab remains available with its negative results.

Twelve separate structural-shift cases contain 192 worlds; four policies and four budget cuts produce 3,072 correlated episodes. Training families have three queries; test families have four queries, changed costs and different decision functions.
